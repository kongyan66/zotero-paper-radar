# 任务中心时间与历史清理设计

## 目标

让任务中心能够追溯每次执行，并降低历史任务堆积对界面的影响：

- 显示任务开始时间、完成时间和耗时。
- 已完成、失败、已取消、已中断任务支持单条清除。
- 一键清空全部历史任务，但保留运行中和排队任务。
- 清理只删除 `operation_tasks` 记录，不影响推荐结果、画像、Embedding 缓存、摘要缓存或 Zotero 条目。

## 交互

- 每条任务的时间信息使用本地化日期时间显示。
- 运行中的任务显示开始时间和当前耗时；未开始任务显示创建时间。
- 完成或失败任务显示开始时间、结束时间和总耗时。
- 历史任务显示“清除”按钮；运行中和排队任务不显示清除按钮，只保留取消操作。
- 任务中心标题区域增加“一键清空”按钮。
- 一键清空弹出确认提示，确认后删除所有非 `queued/running` 任务。
- 清除后保留任务中心当前筛选页和空状态；不改变业务缓存。

## 数据层

- 在 `OperationTaskRepository` 增加按任务 ID 删除和批量清理历史任务的方法。
- 删除/批量清理后复用现有订阅通知刷新视图。
- 执行中的任务由运行协调器保护；清理方法不会删除 `queued` 或 `running` 记录。

## 测试

- 删除单条历史任务，运行中任务不会被删除。
- 一键清空只删除历史状态，保留运行中和排队记录。
- 时间字段正确映射，任务行显示开始/完成时间和耗时。
- 清除按钮和一键清空按钮触发正确回调并刷新列表。
- 现有任务取消、继续、重试和推荐/画像数据测试继续通过。
