# 推荐页画像筛选与折叠设计

## 目标

优化 Zotero arXiv Daily 推荐页的空间利用和画像筛选体验：

- 兴趣画像区域可以折叠，减少画像详情对推荐结果的占用。
- 画像筛选支持稳定的多选操作，不依赖容易被 Zotero 混合 XUL/XHTML 页面裁剪的原生多选下拉层。
- 保留现有 `profileIDs` 多画像筛选数据结构和推荐算法。

## 交互设计

### 画像区域

- 使用原生 `details/summary` 语义实现展开与折叠。
- 默认展开，保证现有用户打开页面即可看到画像内容。
- 标题行显示“兴趣画像”和折叠/展开状态；画像结构操作仍在展开内容中。
- 折叠后保留标题行和必要操作，推荐结果区域自动获得更多空间。
- 只保存当前页面状态，不新增 Zotero 偏好设置。

### 画像筛选

- 用按钮 + 定位菜单替代 `select[multiple]`。
- 菜单内使用复选框，包含“全部兴趣”和所有未停用画像。
- 选择具体画像时取消“全部兴趣”；取消所有具体画像时恢复“全部兴趣”。
- 按钮文本显示当前选择摘要：`全部兴趣`、单个画像名称或`已选 N 个兴趣`。
- 点击按钮切换菜单；点击菜单外部或按 `Escape` 关闭。
- 更新画像列表时保留仍然有效的选择，移除已停用或已不存在的画像。

## 实现边界

- 只修改推荐页 UI 组件和对应样式，不修改画像存储、推荐服务和排序逻辑。
- 所有新增 DOM 使用 XHTML 命名空间，兼容 Zotero 9 混合文档。
- 菜单使用足够高的层级和定位上下文，避免被工作区滚动区域裁剪。
- 控件提供 `aria-expanded`、`aria-haspopup`、`aria-controls` 等状态；复选框保持原生键盘可操作性。

## 测试与验收

- 画像视图默认展开，点击标题控制可展开/折叠。
- 画像菜单可打开、关闭、选择一个或多个画像，并正确返回 `profileIDs`。
- “全部兴趣”和具体画像选择状态互斥且可恢复。
- `setProfiles` 更新后不会丢失仍有效的选择。
- 菜单外部点击和 `Escape` 可以关闭菜单。
- 现有推荐页、画像操作和任务中心测试继续通过。
- 重新构建 XPI，并在 Zotero 9 中验证画像折叠和画像筛选不被裁剪。
