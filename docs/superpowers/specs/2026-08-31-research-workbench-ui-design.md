# 研究工作台 UI 设计

## 目标

将推荐页优化为面向日常研究阅读的工作台：推荐结果占据主要注意力，画像和任务中心提供足够上下文但不抢占空间。

## 视觉与布局

- 顶部工具栏采用紧凑的状态与操作分组，状态、缓存时间和筛选控件保持清晰分层。
- 画像区域默认收起，摘要行显示画像总数及近期/长期数量；展开后保留现有关键词、论文数量、质量指标和代表论文。
- 推荐结果保持主列，卡片减少无效留白，优先显示标题、相关度、命中画像和可解释信息。
- 任务中心保持右侧窄栏，当前运行置顶，历史任务显示目标数量、处理阶段、执行时间和错误操作。
- 宽窗口使用两列布局，窄窗口顺序改为工具栏、画像、推荐、任务和诊断，避免横向裁剪。

## 交互与状态

- 画像折叠使用原生 `details/summary`，保持键盘可操作性。
- 画像筛选使用复选菜单，支持多选、清除全部、点击外部和 `Escape` 关闭。
- 推荐空状态明确说明“没有新论文”或“暂无缓存”，不显示无上下文的大面积空白。
- 错误状态显示具体上游服务和下一步操作。
- 控件补充 hover、按下和 focus 状态，数据数字使用等宽数字特性。

## 边界与验证

- 继续使用现有 Zotero 9 XHTML、TypeScript 和原生 CSS，不引入新框架或外部字体。
- 不改变推荐算法、画像数据结构、模型请求和业务数据库。
- 覆盖宽窗口、窄窗口、加载、成功、空结果、失败和无画像状态。
- 运行类型检查、单元测试、集成测试、Zotero UI 测试并重新构建 XPI。
