# Zotero Paper Radar v0.1.0-beta.4

Zotero Paper Radar（论文雷达）是原 Zotero arXiv Daily 插件的新名称。
在 Zotero 内根据文献库构建兴趣画像、检索 arXiv 论文并查看推荐理由。

## 本次更新

- 统一插件名称、安装包、项目首页和更新地址。
- 近期与长期兴趣画像，可编辑、锁定、停用和调整。
- 画像、时间范围、推荐数量和 arXiv 分类多选工具栏。
- 七天推荐历史与窗口内去重，展示匹配画像和评分依据。
- 可选中文摘要，支持硅基流动、火山方舟及 OpenAI-compatible 模型服务。
- 任务中心显示执行时间、检索数量、候选数量、推荐数量和向量缓存复用情况。
- 修复下拉菜单浮层、透明背景和工具栏控件对齐；摘要使用推荐栏可用宽度。

## 安装与升级

需要 Zotero 9.x。下载 `zotero-paper-radar.xpi`，在 Zotero 插件管理器中选择
“从文件安装插件”，安装后重启。

原插件 ID、偏好设置前缀和数据库名称均保留，新包作为同一插件升级。
此前版本的用户需手动安装一次新 XPI，以使用新仓库的更新地址。
Embedding 为必需配置，LLM 为可选配置；推荐由用户手动启动。

## 已知问题

- 无新增候选时可能回退显示上一次有结果的推荐，当天零结果批次目前不会显示在推荐日列表。
- 相关度是用于展示的排序分数，不是匹配概率。
- 当前主要验证环境为 macOS 上的 Zotero 9；其他平台仍需进一步实机验证。
