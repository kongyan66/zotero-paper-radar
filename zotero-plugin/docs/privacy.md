# 隐私与数据边界

## 默认行为

插件在本机使用独立 SQLite 数据库保存画像版本、Embedding 缓存、推荐结果、反馈、任务检查点和诊断元数据；不会直接写 Zotero 的 `zotero.sqlite`。推荐和画像任务均由用户在 Zotero 内手动触发。

发送到用户配置的 Embedding 服务的字段只有论文标题和摘要。启用 LLM 时，发送到用户配置的 LLM 服务的字段同样是候选论文标题和摘要，以及固定的摘要处理提示。默认不会发送笔记、全文、文件路径、收藏夹名称、标签、作者私有信息或 API Key。PDF 下载只写入用户选择的 Zotero 条目附件，不把 PDF 发送给模型。

arXiv 查询会访问 arXiv 的公开元数据接口。云端模型服务的保留、训练和地域策略不由插件控制，使用前应阅读该服务的隐私政策；需要更强的数据边界时可配置本地模型。

## Key 与诊断

API Key 仅用于请求认证，日志和诊断导出会移除 Key、Bearer Authorization、Cookie、密码、Token 以及包含凭据的 URL 查询参数。诊断默认不包含论文标题、摘要、笔记、路径或收藏夹名，只保留错误码、耗时、批次、缓存命中、模型指纹和任务状态。

用户显式勾选样例内容后，导出前还需要两次确认；样例数量和标题/摘要长度均有上限，Key 仍会被移除。共享诊断前应再次检查导出文件，并删除本地文件。

## 用户控制

用户可以关闭 LLM、修改或删除模型配置、清理可推导缓存、编辑画像、禁用画像、删除任务记录，并通过 Zotero 插件管理器禁用或卸载插件。反馈只用于本地画像和排序权重学习；没有足够反馈时不会发布新的权重版本。
