# Zotero 9 Beta 冒烟清单

记录：日期、操作系统、Zotero 精确版本、插件版本、Embedding 模型/维数、LLM 是否开启。

## 安装与生命周期

- [ ] 从 XPI 安装，Zotero 9 启动无控制台异常。
- [ ] 插件管理器可启用、禁用、重新启用和卸载。
- [ ] 同一 addon ID 安装新 Beta XPI 后版本正确，迁移成功。
- [ ] 关闭 Zotero 后确认没有插件进程或任务继续运行。

## 首次配置与画像

- [ ] 设置页默认 Embedding 必填、LLM 关闭。
- [ ] 远程 HTTP 被拒绝；回环 HTTP 只有显式确认后可用。
- [ ] Embedding 测试显示模型、维数、耗时；LLM 关闭时不产生网络调用。
- [ ] 语料估算只显示数量、批次和 Token 估算，确认前不发送标题/摘要。
- [ ] 完成设置后只创建一个画像任务，画像页显示近期兴趣、长期兴趣、成员数、代表论文和可编辑覆盖。
- [ ] 用户编辑名称、关键词、权重、代表论文、停用/锁定后，系统画像重建不会覆盖编辑。

## 推荐、反馈与入库

- [ ] 工具栏可选择画像、1 到 30 篇、1/3/7/14 天和默认 `cs.CV + cs.CL`。
- [ ] 手动刷新显示任务阶段、缓存命中、推荐卡片和六项分数解释。
- [ ] LLM 关闭显示原始摘要；开启后显示中文摘要，并可查看原始摘要。
- [ ] 点击稍后、不感兴趣、已读/重复等反馈后状态持久化，重复点击不重复训练。
- [ ] 保存并归类可选择/创建目标收藏夹，重复保存同一论文保持幂等。
- [ ] PDF 成功附件可打开；PDF 失败时核心条目仍保留并可单独重试。
- [ ] 任务取消后检查点保留；重启 Zotero 后状态为 `interrupted`，只有手动继续才恢复。

## 诊断与数据边界

- [ ] 默认诊断导出不含 API Key、Authorization、标题、摘要、笔记、路径和收藏夹名称。
- [ ] 勾选样例内容时触发两次确认，样例数量和文本长度受限。
- [ ] 清理缓存不删除画像、反馈和 Zotero 条目；重建可推导数据后可重新推荐。

在 macOS、Windows、Linux 的 Zotero 9 最新稳定小版本各执行一次；无法执行的项目必须记录原因，不得用“通过”替代。
